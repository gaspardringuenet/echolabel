Implementation details
======================

When launched, the Echolabel reads the source data, chunks it into fixed-width frames, and saves each frame’s metadata in cache. Frames are then converted into images by scaling Sv, and applying a color mapping. Single frequency echograms can be printed using any matplotlib colormap. Three channels can be rendered simultaneously using an RGB mapping [@ariza2022], providing visual intuition on the organisms’ frequency responses. Echogram images are saved in cache. If the output file already exists, it is read and converted into Labelme’s internal annotation format. The Labelme graphical user interface is then launched. As long as the window remains open, the user can add and edit shapes on the dataset’s images. When closing, shapes are converted to (time, depth) coordinates using cached images metadata and the annotation file is (over-)written. In case the output is overwritten, a copy of the pre-session file is stored as failsafe.
